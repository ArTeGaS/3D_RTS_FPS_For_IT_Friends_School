# 3D RTS FPS Prototype

Unity prototype that explores a hybrid of first-person combat and simple RTS / tower-defense building mechanics. The idea is close to a Sanctum-like loop: the player moves and shoots in first person while also placing defensive structures.

## Status

Educational prototype / classroom project. It is useful as a code and gameplay experiment, not as a production-ready game.

## What is included

- First-person player movement and weapon scripts
- Enemy agent, spawn point, bullet, recoil, flash, and HP bar behavior
- Simple building menu and foundation block logic
- Turret behavior for defensive gameplay
- Unity scene and project settings for local exploration

## Project structure

- `Assets/FPS` - player, weapon, enemy, and combat scripts
- `Assets/RTS` - building and turret prototype logic
- `Assets/UI` - build menu UI scripts
- `Assets/Scenes` - Unity scenes

## Opening the project

This project was last worked with Unity `2022.3.36f1`.

Open the repository folder in Unity Hub, let Unity restore packages, then open `Assets/Scenes/SampleScene.unity`.

## Notes

This repository is intentionally kept as a prototype. Some naming, scene setup, and content organization reflect the learning and iteration process rather than a polished final architecture.
